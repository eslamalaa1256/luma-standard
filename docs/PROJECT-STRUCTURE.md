# Project structure
- `index.html`: page structure, links CSS/JS.
- `js/config.js`: all customer content.  `main.js`: startup.  `envelope.js`: seal/flap/card sequence.  `language.js`: AR/EN switching.  `countdown.js`: time-zone-aware countdown.  `gallery.js`: grid and lightbox.  `music.js`: audio button.  `map.js`: map preview and directions.
- `css/variables.css`: palette, fonts, tokens.  `main.css`: base.  `envelope.css`: envelope.  `animations.css`: keyframes, reveals, reduced motion.  `invitation.css`: scenes.  `gallery.css`: gallery and lightbox.  `responsive.css`: tablet/desktop.
- `assets/`: images (hero, gallery, icons, envelope notes), audio, fonts. Folders with only a README are placeholders for customer files.
